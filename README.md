# Idolatry Studio

Site vitrine du studio photo et de tournage Idolatry, situé à Ivry-sur-Seine, près de Paris.

Le site présente le studio, ses espaces et équipements, ses services de location, ainsi que les informations pratiques pour préparer une séance ou un tournage. Il est disponible en français et en anglais.

## Site en ligne

[studio.idolatry.tv](https://studio.idolatry.tv/)

## Structure

- `index.html` : version française
- `en/index.html` : version anglaise
- `styles.css` : styles et mise en page
- `script.js` : interactions du site
- `media/` : photographies, vidéos et visuels
- `favicon.*` et `apple-touch-icon.png` : icônes du site
- `idolatry_studio.png` et `idolatry.png` : fichiers PNG sources des deux logos favicon

## Développement local

Le site est statique et ne nécessite ni compilation ni dépendances Node.js. Ouvrir `index.html` dans un navigateur ou servir le dossier avec un serveur HTTP local pour vérifier les chemins et les médias.

## Publication

Le site est publié depuis la branche `main` sur GitHub Pages, avec le domaine personnalisé `studio.idolatry.tv` défini dans `CNAME`. Les changements publiés sur `main` sont déployés par GitHub Pages.
